# ForexPro Currency Converter

A responsive currency converter website with real-time exchange rates and historical data.

## Features

- Modern responsive design
- Currency conversion with 20+ currencies
- Historical exchange rate charts
- User authentication (login/signup)
- Live exchange rates table

## Pages

- `index.html` - Home page with features and information
- `converter.html` - Currency converter with chart
- `about.html` - About us page with team information
- `login.html` - User login page
- `signup.html` - User registration page

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- JavaScript (ES6+)
- Chart.js for exchange rate charts
- Font Awesome for icons

## Setup

1. Download all files to a folder
2. Open `index.html` in a web browser

## Note

This is a frontend-only implementation. In a real application, you would need to:

1. Connect to a currency exchange API for live data
2. Implement backend authentication
3. Set up a database for user accounts

The exchange rates and historical data in this implementation are sample data for demonstration purposes.
